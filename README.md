🎬 Movie Data Analysis (Python Notebook)
This project involves exploratory data analysis of a movie dataset using Python. The notebook demonstrates data cleaning, visualization, and key insights related to movie trends and metrics.

📁 File
Movie_data_Analysis_2.ipynb – Jupyter Notebook that contains the entire analysis code and visualizations.
