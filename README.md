
# 🎬 Movie Data Analysis (Python Notebook)

This project involves exploratory data analysis of a movie dataset using Python. The notebook demonstrates data cleaning, visualization, and key insights related to movie trends and metrics.

---

## 📁 File

- **`Movie_data_Analysis_2.ipynb`** – Jupyter Notebook that contains the entire analysis code and visualizations.

---

## 🚀 How to Use

### 🔹 1. Clone the Repository (All Platforms)

```bash
git clone https://github.com/your-username/movie-data-analysis.git
cd movie-data-analysis
```

---

### 🔹 2. Set Up Python Virtual Environment

#### ▪ For macOS/Linux/Unix:

```bash
python3 -m venv env
source env/bin/activate
```

#### ▪ For Windows (CMD or PowerShell):

```cmd
python -m venv env
env\Scripts\activate
```

---

### 🔹 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

If `requirements.txt` is not provided, install libraries manually:

```bash
pip install pandas matplotlib seaborn numpy
```

---

### 🔹 4. Run the Notebook

#### ✅ Option A: Run Locally (Jupyter)

Ensure Jupyter is installed:

```bash
pip install notebook
```

Then start the notebook:

```bash
jupyter notebook Movie_data_Analysis_2.ipynb
```

You can also open it in IDEs like **VSCode** or **PyCharm** that support Jupyter notebooks.

---

#### ✅ Option B: Run on Google Colab (No Installation Required)

1. Go to [Google Colab](https://colab.research.google.com/)
2. Click on **File > Upload notebook**
3. Select and upload `Movie_data_Analysis_2.ipynb` from your system
4. Run the cells using `Shift + Enter`
5. Install missing packages if needed:

```python
!pip install pandas matplotlib seaborn numpy
```
